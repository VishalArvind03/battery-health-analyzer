# Battery Health Analyzer Project

## Goal
Build a practical Python project focused on battery data analysis, SOH estimation, simulation, and basic optimization. The aim is to strengthen my profile for battery systems, BMS, validation, simulation, and automotive internship roles in Germany.

## Learning Rule
I should understand every file, function, library, and result well enough to explain it in an interview. AI can help write and review code, but I must understand the engineering logic.

## Phase 1: Python And Data Basics
- Python basics: variables, lists, dictionaries, loops, functions
- File handling: CSV and Excel files
- Pandas: DataFrames, filtering, grouping, cleaning
- NumPy: arrays and numerical calculations
- Matplotlib/Plotly: basic engineering plots

## Phase 2: Battery Data Analysis
- Load battery cycling data
- Calculate cycle count, capacity, SOH, voltage/current/temperature trends
- Plot degradation curves
- Identify abnormal cycles or noisy data

## Phase 3: Prediction And Simulation
- Use scikit-learn for simple SOH prediction
- Use SciPy for curve fitting or charging optimization
- Use PyBaMM for basic battery simulation

## Phase 4: Presentation
- Build a small dashboard using Streamlit or Plotly
- Write a clean README
- Add results, limitations, and future improvements
- Prepare CV bullet points and interview explanations
